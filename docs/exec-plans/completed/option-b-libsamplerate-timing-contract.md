# Execution Plan: Option B libsamplerate Timing-Contract Comparator

## Purpose

Measure one pinned libsamplerate release as a prototype-only bandlimited DSP backend. It must not change AudioNLE's integer Project/Source/rational edit authority.

## Lifecycle

`src_new`, `src_reset`, state destruction, and configuration occur only on a control thread. The process path may call only prepared-state `src_process` with fixed caller buffers.

## Scope and stop conditions

Run LS0--LS22 in the authorised request, creating the requested feasibility and evidence documents. Stop without third-party patches if upstream integration fails, or classify negatively/inconclusively if bounded preroll, nonzero starts, deterministic accounting, or callback safety is not demonstrated. No production selection, FFmpeg, GUI, devices, or Domain change is permitted.

## Completion

Complete only with the required evidence, one candidate classification, a wrapper-burden classification, and a next backend-selection action. The completed integer-ZOH plan remains unchanged.

## Progress

LS0--LS4 pass: the pinned CMake subproject builds and static-links on Windows/MSVC, and three fresh caller-buffer `SRC_SINC_BEST_QUALITY` runs per required ratio are identical. LS5--LS22 remain mandatory before classification.

## LS5--LS8 outcome

PASS. The wrapper phase-lattice and exact discard model passes every reduced phase class, all required deterministic content, source-start handling, fresh-state repeatability, and reset equivalence. The bound is **Bounded but empirically chosen**: nominal 1024 native frames plus phase rounding (at most Q-1) is not formally derivable from a public libsamplerate delay/filter-support API. LS9 may begin; this does not classify libsamplerate as selected or production-safe.

## LS9--LS12 outcome

PASS; proceed to edit/lifecycle gates. Both ratios reconstruct the same exposed Timeline range under 128, 256, and deterministic irregular graph/native partitions (max and RMS error <= `2e-5`) without graph-boundary reset or state replacement. Generation-stamped cache pages reject an old page; its SRC state is discarded and a fresh state renders current-generation output. The expanded 320/147 invalidation row requires nine 257-frame pages; the fixture cache is therefore fixed at 9252 bytes, with zero AudioNLE callback reader/wait/allocation/fallback operations and no duration-scaled retained PCM.

Carried constraint: **AudioNLE callback contract proven; libsamplerate internal realtime safety partially unproven.** Source inspection observes allocation in state creation/destruction, not the examined `src_process` dispatch, but this fixture does not interpose all CRT/OS allocation or lock primitives. LS13--LS19 may begin; LS20--LS22 remain mandatory before candidate classification.

## LS13--LS19 outcome

PASS; proceed to quality/final comparison. Both ratios pass forward/backward/repeated fresh-state seeks; integer logical trims and re-expansion; Source 0/1/small-offset boundaries; exact, fractional-phase, and ordinary split starts; Domain-coordinate-only reconstruction; isolated overlapping/disjoint view states and recreation; and logical/physical source-end accounting. The unchanged empirical `1024 + phase-rounding` preroll remains sufficient. Filter settling is physical SRC behavior, not AudioNLE Effect Tail semantics. The LS9--LS12 callback and backend-runtime constraint carries forward unchanged. LS20 may begin.

## LS20--LS22 outcome — complete

PASS. Fixed `SRC_SINC_BEST_QUALITY` measurements at 44.1->48 and 48->44 show no material passband defect, stable finite and repeatable output, and sampled alias/image behavior materially better than IntegerRationalZoh. Integration complexity is a **Moderate SRC integration subsystem**. Final classification: **libsamplerate Proceed with Constraints**. Constraints are the empirical, converter-mode/ratio-specific 1024-frame preroll policy and partially unproven libsamplerate internal realtime safety; AudioNLE callback safety remains proven. Select libsamplerate for the current Option B prototype only, not as an irreversible production commitment. The parent backend-selection plan remains active.
