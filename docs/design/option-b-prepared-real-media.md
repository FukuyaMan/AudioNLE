# Prepared Conversion Real-Media V1 Boundary

The real-media vertical slice adds a decoder-provider contract: a worker-owned `AudioFormatReader` reads bounded native frames at integer sample offsets into caller-owned planar buffers. The conversion worker uses one libsamplerate BEST state per source channel and emits interleaved project-rate float32 pages. Interleaved storage is selected because the persistent payload and SourceNode-facing copies use the same layout; callback must not transpose layout.

Artifact identity includes source identity/revision, selected stream identity, source/project rates, reduced P/Q, channel count/layout, backend pin/config fingerprint, BEST quality, reconstruction policy, and format version. The persistent artifact is derived/session data, never a source modification or Domain authority. Cache paths are under the session cache root and use deterministic artifact identity, not paths beside source media.

The persistent record is fixed-size: a `PageRecord` followed by one complete 256-frame interleaved payload (unused final-page samples are zero). Therefore a reader validates the header/key off callback and addresses a page without a duration-scaled RAM index: `sizeof(Header) + pageIndex * recordBytes`. It opens/reads/checksums only on the worker side.

The residency prototype has 16 fixed RAM slots and an 8-entry request table. Callback lookup scans only this bounded storage, pins a matching Ready slot, verifies its page/generation/publication version after pinning, copies it, then releases the pin. A miss coalesces a demand request or returns `Unavailable` with deterministic silence; it never opens a file, decodes, invokes SRC, waits, locks, allocates, or evicts. The worker fills a private page, validates it, then release-publishes it. Worker-only least-age eviction skips Loading and pinned slots. Explicit requests precede a one-page `N+1` prefetch; prefetch never chains indefinitely.

The Windows IAT harness directly compiles and executes this same residency runtime (rather than a pre-filled callback buffer). It creates a persistent stereo artifact, opens it and services loads off callback, then audits resident copy, stereo seam, cold request publication, post-worker reload, eviction/reload, and a callback concurrent with worker file I/O. In each callback section the intercepted CRT, heap, lock, wait/sleep, and file-I/O counters are zero; prepared callback SRC processing/fallback is zero.

This remains an engine-private prototype boundary. One bounded worker services its request table in the evidence fixture; it is not a thread-per-artifact design. Artifact replacement/reopen is controlled by identity validation and generation tokens. Corruption, truncation, deletion/unavailability and stale generation leave a page unavailable with no realtime SRC fallback. FFmpeg/compressed/container decoding, selected streams, UI progress, and integration into the production shared worker / SourceNode lifecycle remain outside this milestone.
