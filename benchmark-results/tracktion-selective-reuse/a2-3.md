## Authority and mapping policy

The framework-free `DomainState` stores `projectTimelineSampleRate`, `sourceSampleRate`, `timelinePositionSamples`, `sourcePositionSamples`, `sourceDurationSamples`, and `timelineDurationSamples` as signed 64-bit integers. The fixture is exactly source `[0,44100)` and Timeline `[0,48000)`. `SourceEvent` positions are Source samples; receiver observation is Timeline samples. Floating-point seconds are not authoritative state.

For this fixture only, both directions use non-negative nearest-integer rational conversion, with exact half ties upward:

```text
Source -> Timeline: floor((sourceOffset * 48000 + 22050) / 44100)
Timeline -> Source: floor((timelineOffset * 44100 + 24000) / 48000)
```

The implementation checks the multiplication bound before each `int64_t` multiply. This is a scheduling policy for a sparse generated-event fixture, not a sample-rate-conversion algorithm and not a production policy. `MappedSourceNode` receives `ProcessContext::referenceSampleRange`, maps Domain source events directly into that requested Timeline range, and contains no Tracktion source reader/resampler path.
