## Fixture graph and authority

```text
framework-free DomainState
  -> DomainControlledSourceNode(s)
  -> deterministic ProcessorNode(s) (Clip-equivalent)
  -> public SummingNode when more than one source (Track Mix)
  -> deterministic ProcessorNode(s) (Track-equivalent)
  -> deterministic ProcessorNode(s) (Master-equivalent)
  -> public SimpleNodePlayer -> caller-owned float observation
```

`ProcessorState` is framework-free: ID, Add/Multiply kind, parameter, enabled flag, and Domain order. The wrapper Nodes are runtime-only adapters. They own their direct input with `unique_ptr`, declare it through `getDirectInputNodes`, copy its Tracktion graph buffer, then apply deterministic Add or Multiply in that graph-managed process buffer. This is not a manual buffer chain outside Tracktion graph traversal.

Domain State stays authoritative. It is compared before/after every render; runtime does not persist, feed back, or synchronize to it. No Synchronization Group/Member, Clip Group, or Ripple semantics is created or delegated.
