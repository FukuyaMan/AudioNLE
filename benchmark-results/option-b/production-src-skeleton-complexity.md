# Production SRC Skeleton Complexity

The skeleton is a **Moderate production SRC component**. It implements the intended private boundary without libsamplerate types in Domain APIs, but it necessarily owns configuration versioning, empirical policy status, physical range/discard planning, prepared-generation checking, fixed capacity and lifecycle reconstruction.

Remaining work is deliberately separate: 96-kHz v1 continuous-reference validation, wider matrix, deep allocator/lock audit, density and cache-pressure benchmarking, long-form stress, release notices, failure propagation and production persistence/versioning policy.
